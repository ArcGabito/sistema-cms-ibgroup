# Sistema CMS de IBGroup S.A.C.

![Portada](core/client/public/assets/portada.png)

Este repositorio contiene el ecosistema de servicios que conforman el CMS de IBGroup S.A.C. para la creación y gestión de contenido empresarial y promocional de sus servicios de outplacement.

----

#### Clona el proyecto en local:

```bash
curl -fsSL https://raw.githubusercontent.com/ArcGabicho/sistema-cms-ibgroup/master/scripts/setup.sh | bash
```

#### Deployar el proyecto en Azure:

```bash
curl -fsSL https://raw.githubusercontent.com/ArcGabicho/sistema-cms-ibgroup/master/scripts/deploy.sh | bash
```
